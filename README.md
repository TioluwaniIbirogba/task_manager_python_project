# Task Manager

Task Manager is a Python project used for making a list of things that are to be do. It helps in remembering tasks.

# Features
- View tasks list
- Add task
- Mark task as completed
- Delete task
- Exit program

# How to run it
Start the program, then write the number of what you want to use in the task list menu.

# Technologies
- Python
- JSON
- Object oriented programming

# What I learned
- Handling JSON
- Exception handling/input validation using try/except in python
- Designing menu-driven programs
- File persistence
